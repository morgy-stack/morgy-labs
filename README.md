## Getting Started

```bash
git clone https://github.com/morgy-stack/morgy-labs.git
cd morgy-labs
python -m venv .venv
```

Activate the environment:

**Windows**
```bash
.venv\Scripts\activate
```

**macOS/Linux**
```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
